# Earlier experiments

The active project is [Portfolio Agent](../README.md). This directory preserves the earlier research harnesses, public fixtures, results and offline tests; it is not part of the deployed runtime.

Run the historical tests from the repository root:

```sh
PYTHONPATH=experiments python -m unittest discover -s experiments/tests -v
```

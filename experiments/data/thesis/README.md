# Evidence packets

The initial packet is a small, builder-checked selection from Microsoft's July 29, 2026 earnings release and earnings call. It is not a complete company analysis or a live market feed. The release's cash flow statements are unaudited. Values use the twelve-month columns, in USD millions, for fiscal years ending June 30.

| Calculation | FY2026 | FY2025 |
| --- | ---: | ---: |
| Operating cash flow | 182,935 | 136,162 |
| Cash outflow for additions to PP&E, shown positive | 115,948 | 64,551 |
| Cash after PP&E, calculated by subtraction | 66,987 | 71,611 |

The calculated measure is company-wide cash from operations less cash PP&E. It does not isolate AI returns or include all finance-lease commitments. Management commentary is attributed and forecasts remain forecasts.

Each fact or context item has a stable evidence ID and source ID. The research model cites those IDs; the public view renders numeric facts from this packet. A reviewer still has to check whether the cited evidence actually supports the model's claim.

To update a thesis, prepare a new packet for the same thesis ID, with a new evidence date and dated sources, then run a new research revision. Prior revisions retain their own packet and its hash in private storage. Never relabel old evidence as a new observation or replace earlier thesis history.

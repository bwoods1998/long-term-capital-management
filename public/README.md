# Public records

The current website displays a validated paper-portfolio checkpoint at [blakewoods.us/portfolio/](https://blakewoods.us/portfolio/). Its saved state is served by `/api/portfolio/state`, with a bundled fallback. Visitors cannot initiate research or trading.

Earlier generated reports are in [the experiment archive](../experiments/public/). Their protocols are in [the development records](../docs/history/README.md).

Raw source captures, model responses, run databases and credentials remain private.

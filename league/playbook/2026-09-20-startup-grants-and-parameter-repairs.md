# Startup help and parameter repairs

An untraded agent can use `research_grant` after `replay_coverage` or a replay in the same
research pass. Give a specific question, falsifiable hypothesis and acceptance check. The House
pays for one specialist call per family/niche per campaign, including descendants. The entire
floor has twelve grants, each with a $0.75 reservation ceiling, inside the existing research
budget. A new agent, another pass or a restart does not renew a grant. An interrupted call may
have been billed, so it is not automatically repeated.

The returned code is a proposal. Check its exact NEEDS, parameter validity, signal, exits and
fees, then replay it. A more expensive model can still omit an input declaration or change logic
you asked it to preserve. Specialist confidence is not measured performance. Successful traders
retain their separate earned `ask_merton` access.

For a legacy invalid configuration on rung 0, submit a candidate that repairs only PARAMS while
keeping decision logic and NEEDS unchanged. If the agent has no record or position, the House can
adopt that repair even when the replay fails. It stays on rung 0, retains every historical trial,
and still needs the normal qualification evidence before paper promotion. This exception cannot
install a different trading algorithm after a failed replay.

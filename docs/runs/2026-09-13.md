# Portfolio research · September 13, 2026

The first sustained coordinator started at **09:10 Pacific**, with a planned **14:10** deadline. It was deliberately stopped early to build persistent weekday operation. This is a completed record of that shorter experiment, not a completed five-hour run.

## Recorded work

| Scope | Result | Inference cost |
|---|---|---|
| Main coordinator | 259 requests: 249 completed, 10 failed; all request costs reconciled. | $8.717983462 |
| Two research forks | Ten completed requests across five matched companies; all ten passed source checks. | $0.20152990 |

The source bank covered all 503 S&P 500 securities. DeepSeek V4 Pro, Kimi K2.6 and GLM 5.3 researched companies; Kimi K3 reviewed proposed allocations. The run exercised repeated research, source matching, completion windows, memory comparisons, ordinary caching, a confirmed Supercache write, Voyage events, live publication and recovery.

Seven main-request failures came from explicitly rejected ASAP request settings. These were reconciled using the original request identities and rejection evidence; they were not accepted inference. The corrected request construction is covered by regression tests. Other failures remain in the recorded results rather than being replaced with successful retries under new identities.

The public journal contains **258 settled records**: 242 passed the publication/source checks, six were unverified and ten failed. The operational cache-initialization request is excluded from investment history. Request completion and source-check success are different measures.

## Fork comparison

Both arms answered the same five company questions—NVDA, JPM, XOM, UNH and CAT—using Kimi K2.6 Flex. One received the full-universe context; the other received focused context.

| Context | Source checks | Inference cost | Mean observed request time |
|---|---|---|---|
| Full universe | 5 / 5 passed | $0.12895520 | 159 seconds |
| Focused | 5 / 5 passed | $0.07257470 | 252 seconds |

Focused context cost less in this sample; it did not finish faster. The full-context arm benefited from substantial ordinary-cache reuse. Five paired companies, one model and one draw per arm cannot establish a general advantage. Context selection also changes information supplied; this is not a controlled test of context length alone. Observed elapsed time includes provider waiting and polling.

The first launch failed before inference because cloned machines did not inherit the HTTP credential binding. The controller now explicitly binds each child's reviewed policy before starting it. That failed launch's terminated resources cost **$0.010004266** in compute. The successful retry used the original reserved allocation and cost **$0.015395984** in compute: seed $0.005026217, full-context child $0.005178500, focused child $0.005191267. Main-host compute and earlier integration tests are tracked separately from the inference figures above.

## What this established

The project preserved accepted request identities, checked financial claims against dated sources, delivered trace events, maintained public checkpoints, and recovered exact research state. The fork failure exposed a real lifecycle assumption and produced a tested fix. Email connection delivery was confirmed by the owner.

It did **not** establish alpha, forecast accuracy, a universally better memory policy, or successful autonomous weekday operation. The paper account held $100,000 of virtual starting capital; Sunday research cannot create a regular-session fill. No investment performance is claimed.

The stopped coordinator and drained journals are preserved; its Sailbox is asleep and its local watchdog is stopped. The next system keeps one portfolio across bounded weekday sessions, uses independent cloud supervision and private backups, and evaluates narrowly defined memory changes on future evidence dates. Spending is useful only when it buys evidence, operational reliability or measurable experimental information.
